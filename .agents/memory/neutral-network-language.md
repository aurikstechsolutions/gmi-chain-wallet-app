---
name: Neutral network language
description: Product naming guidance for the GMI Wallet network operations experience
---

Use Network, Node, Network Access, and Rewards in user-facing wallet copy. Keep the existing validator terminology in API routes, storage keys, heartbeat contracts, and internal types unless the backend contract is intentionally migrated.

**Why:** The wallet should feel like a professional network and operations product without breaking the existing MChain heartbeat and API integrations.

**How to apply:** When adding or editing visible labels, alerts, onboarding copy, notifications, and navigation, avoid exposing protocol-specific validator terminology; preserve internal identifiers for compatibility.
